## 常见问题

**Q：需要联网吗？**
不需要。下载后是完全离线的本地文件，断网也能正常抽奖。Excel 读写所需的解析库也已内联在文件里，不依赖任何 CDN。

**Q：名单和照片会上传到服务器吗？**
不会。软件全程在本机浏览器里运行，不发起任何网络请求（源码可直接搜索 `fetch` / `XMLHttpRequest` 验证），照片存在浏览器本地的 IndexedDB 里，离开你的电脑就没有任何副本。

**Q：支持多少人？**
设计容量 500 人，几百人的年会名单完全没问题；照片模式下采用缩略图 + 按需加载，大量照片也不会卡。

**Q：会不会重复抽到同一个人？**
不会。同一场活动内中奖者会自动从候选池移除；抽错了还可以「作废并重抽」，作废者不会再次进入奖池。

**Q：照片文件名要怎么命名？**
直接用姓名做文件名即可，`张伟.jpg`、`01_张伟.jpg`、`01-张伟.png` 都能正确识别出「张伟」。

**Q：能改界面上的活动名称吗？**
可以，在设置里把标题改成你公司的实际活动名即可；背景图、配色、音效也都能换。

**Q：Mac 能用吗？**
可以。任何现代浏览器都能打开，Windows / macOS / Linux 都一样。

**Q：为什么是一个单文件，而不是安装程序？**
因为年会现场最怕"装不上"。单个 HTML 文件没有安装环节，拷过去就能用，也不会因为缺少运行库而失败。

## 技术说明

- 纯前端实现：HTML + CSS + 原生 JavaScript，无框架、无构建步骤、无外部依赖（Excel 解析库 SheetJS 已内联）。
- 单文件打包：所有样式与脚本内联，因此只有一个 `.html` 文件，便于分发。
- 本地文件读写：Excel 导入导出在浏览器内完成，不经过网络。
- 照片存储：IndexedDB 分库管理 —— 轻量缩略图常驻内存保证滚动流畅，大图按需异步加载（带 LRU 上限），几百张照片也能稳定运行。
- 3D 轮盘使用 Web Animations API 在合成线程运行动画，抽奖过程中不做高频 DOM 刷新。
- 抽签随机性：Fisher-Yates 洗牌 + 均匀随机取样，不存在 `sort(() => Math.random() - 0.5)` 式的偏差。
- 兼容性：Chrome / Edge / Firefox / Safari 的近几年版本均可。
