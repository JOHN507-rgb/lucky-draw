## 常见问题

**Q：需要联网吗？**
不需要。下载后是完全离线的本地文件，断网也能正常抽奖。

**Q：名单会上传到服务器吗？**
不会。软件全程在本机浏览器里运行，不发起任何网络请求，名单不会离开你的电脑。

**Q：支持多少人？**
几百到几千人的名单都能正常处理，取决于你电脑的性能。导入时会做一次解析，之后抽奖是瞬时完成的。

**Q：会不会重复抽到同一个人？**
不会。同一场活动内中奖者会自动从候选池移除。如果你确实想让某人可以重复参与（比如多轮小游戏），可以在设置里关闭去重。

**Q：能改界面上的活动名称吗？**
可以，在设置里把标题改成你公司的实际活动名即可。

**Q：Mac 能用吗？**
可以。任何现代浏览器都能打开，Windows / macOS / Linux 都一样。

**Q：为什么是一个单文件，而不是安装程序？**
因为年会现场最怕"装不上"。单个 HTML 文件没有安装环节，拷过去就能用，也不会因为缺少运行库而失败。
